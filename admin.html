新增商品

商品規格與庫存＊

每個規格請填名稱與庫存數量，例如 0.5mm／庫存 20。顧客選擇規格後才能加入購物車。

＊必填。每個規格都要填寫規格名稱與庫存整數（可填 0）。按下加入商品或儲存修改後，系統會自動下載 products.json。

目前商品

新增、修改或刪除商品後，系統會自動下載 products.json。請將下載檔上傳 GitHub 根目錄並覆蓋舊檔，官網才會更新。也可使用右上方「下載更新檔」再次下載。
